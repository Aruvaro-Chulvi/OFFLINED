libpst / readpst
================

Offlined uses the `readpst` utility from the libpst project to import
Outlook `.pst` mailboxes in the Mailbox section. It is invoked as a separate
external process (mere aggregation); the GPL copyleft does NOT extend to the
proprietary code of the Offlined application.

NOTE
----
The `readpst` binary is OPTIONAL and may not be bundled with every build of
Offlined. When it is absent from `/bin/`, the Mailbox only imports `.mbox`
files (handled by the Python standard-library `mailbox` module, which needs no
separate attribution). If you distribute a build that DOES include the
`readpst` executable, you must ship this notice, keep the binary as an
independent process, and make its corresponding source available under the
terms above.
